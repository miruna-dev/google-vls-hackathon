# Vision & Language Hackathon – Guardrail Enforcement & Model Verification

**Award:** 4th Place Finalist – Google Vision and Language Summer School (July 2026)

## Project Overview
This repository contains the solution developed during the final competitive hackathon of the Google Vision and Language Summer School. The goal was to build and optimize an automated inference and verification pipeline subject to strict safety and behavioral guardrails.

## Features
- **Inference Pipeline:** Implemented algorithmic logic and data ingestion via `competition_skeleton.py` to meet challenge benchmarks.
- **Guardrail Enforcement:** Validated model output constraints using `competition_guardrail/` modules to guarantee format compliance and output safety.
- **Error Distribution & Analysis:** Diagnosed failure modes and edge cases with `error_analysis.py` to iteratively improve performance metrics.
- **Automated Verification:** Verified pipeline sanity and compliance via `verify.py`.

## Tech Stack
- **Language:** Python 3.10+
- **Concepts:** Model Validation, Error Analysis, Guardrail Safety Systems, Pipeline Optimization
